# Clarify Request

Produce a task brief another AI can execute without this conversation. This skill completes the brief; the described work is a separate assignment.

## Establish the brief

- **What and why:** the requested work, who needs it, and the problem or situation behind it.
- **Goal:** the change the work should enable. A dashboard is an artifact; knowing which orders need attention is an outcome. Preserve an explicitly chosen solution while exploring its purpose.
- **Completion criteria:** observable conditions and a way to check them. Ground quality expectations in agreed examples, references, or evidence-based targets. Distinguish delivery acceptance from impact measurable only after delivery.

Resolve scope, exclusions, constraints, priorities, required resources and tools, access limits, and output format and destination when they affect the assignment. Establish the executor's freedom to revise the approach and which changes need a user decision. Leave replaceable implementation choices to the executor.

## Resolve consequential gaps

Reuse established answers. Resolve factual gaps from relevant materials or the environment; ask the user for intentions and tradeoffs. Prioritize missing or conflicting answers that would change the assignment or its acceptance, scaling questions to the request.

Ask related questions in manageable rounds, waiting for answers before asking dependent questions. When the user cannot articulate an answer, use concrete situations, past experiences, or alternative outcomes and their consequences to help them decide. Use acceptable and unacceptable examples to clarify subjective expectations.

As understanding develops, show a concise draft the user can correct. Keep proposals and suggested defaults distinct from user decisions. If the goal remains uncertain, offer a bounded investigation that produces the basis for a decision as a possible assignment.

## Deliver

Address the brief directly to the executing AI, carrying forward the established requirements, delegated choices, and context and source locations needed to act. Choose a structure suited to the work.

Finish when no unresolved user decision would materially change the assignment or how completion is judged. If the user stops sooner, return the draft with the decisions needed before dependent work begins.
