# 연결 작업

연결 이슈는 작업 대상 `PL-*`와 문서의 `related_issues`다. `show`로 확인한다. 누락·종료면 중단한다. 없으면 Issue Ledger에 접근하지 않는다.

Design과 기존 Plan·Spec은 ID를 저장한 뒤 이슈마다 `link-work`를 실행한다. `scripts/issue-ledger.js link-work --help`가 계약이다. 같은 입력은 `no-op`이며 ID·경로·요약·다음 행동이 일치해야 완료다. 이 명령은 이슈를 생성·재개·해결하지 않는다.

구현은 활성 Design 또는 호환되는 기존 Spec 링크를 기준으로 한다. 요청과 다르면 `development-design`으로 맞춘다. 준비 때 확인한 근거는 재사용하며, 시작과 최종 통과·중단 때 필요한 진행 상태를 갱신한다.

최종 통과 뒤 증거 계약으로 해결을 판단한다. 미충족 조건이 있으면 활성 상태를 유지한다. 분할 계획은 Design과 연결하고 대응된 마일스톤만 갱신한다. 추적을 요청받은 독립 결과만 하위 이슈로 기록한다.
