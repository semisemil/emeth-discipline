# Measurement

Define the measured outcome, units, workload and comparison conditions from the request.
Use the project's existing benchmark or measurement tools.
For a comparison or requested improvement, capture the baseline before changing the measured work.

Keep compared builds, inputs and execution conditions equivalent for the claim being tested.
Distinguish setup from timed work, and verify that the measured work ran and produced correct results.
Repeat enough to assess variability and retain the run results; report the run count and relevant spread with the comparison.
If correctness or comparability is unresolved, report that limit with the result.

For agent-workflow usage or cost comparisons, include the participating agents and distinguish recorded usage from estimated costs.
Report the commands, conditions, results and evidence needed to assess the claim.
For requested improvements, combine measurement with the [implementation workflow](../SKILL.md#implementation) and repeat the comparison on the resulting artifact.
