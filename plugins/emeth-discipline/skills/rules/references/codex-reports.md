# Reports and work results

Follow the report type's conventions for purpose, method, results, and conclusions.
Start chat summaries with the outcome.
Keep related sentences in one paragraph and show each on a new line.

Use concrete verbs to say what happened.
Build each sentence and paragraph on what the reader just learned.
Keep evidence and relevant uncertainties with the result.
If the reader must decide, explain how the findings affect each option.

For measurements or experiments, present the method as labeled fields or a table covering the target, comparison conditions, environment, inputs, procedure, metrics, and repetitions.
Use concise table entries or unbulleted label-value lines for factual report content.
Use sentences for reasoning and interpretation.
Distinguish measured results, interpretations, and unverified items.
