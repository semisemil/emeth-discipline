CLI 작업 완료 알림에 --quiet 옵션을 추가하는 변경을 설계해 주세요.
구현은 하지 마세요.

현재 CLI의 run 함수는 인자를 읽고 작업을 실행합니다.
reportProgress 함수는 시작과 완료 메시지를 stderr에 씁니다.
성공한 작업의 JSON 결과는 stdout에 쓰고 종료코드 0을 반환합니다.
실패하면 reportError 함수가 오류를 stderr에 쓰고 종료코드 1을 반환합니다.

--quiet가 있으면 시작과 완료 메시지만 생략해야 합니다.
JSON 결과, 실패 오류와 종료코드는 지금과 같아야 합니다.
--quiet가 없을 때의 동작도 유지해야 합니다.
이 옵션의 설정 파일 저장이나 다른 출력 형식은 필요하지 않습니다.
