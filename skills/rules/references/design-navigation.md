# Design progress navigation

Create a compact, separate progress document for multi-topic design discussions, even without a final document, and show or link it.
Skip it for short single-topic discussions.

Show the goal, topics, progress, and current position.
Prefer checkboxes (checked when settled) and nested topics; highlight the current topic.

Update only changed parts from conversation context; read only what is needed to recover missing context.
Briefly orient the user at topic transitions; show the full overview only on request or when substantial changes require reorientation.

Retain the document while issues remain or discussion is paused.
At completion of the requested scope:

- With a final document, merge useful topics into its table of contents, matching its structure and removing progress and current-position markers, then delete the progress document.
- Otherwise, delete the progress document without creating a final document.
