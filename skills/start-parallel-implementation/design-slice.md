# Design Slice

Read the ready Design and inspect the code needed to identify work boundaries.
Record or update the implementation work in the Design using [Design editing](../development-design/references/document-editing.md).
Cover the Design's requirements with verifiable work items; keep small tasks unsplit.
Record each item's completion criteria and any dependencies, referring to existing Design details.
Mark parallel groups only when their inputs and interfaces are settled and their change scopes do not overlap.
Preserve the Design's requirements and still-valid completed items; finish by reporting the saved work breakdown.
