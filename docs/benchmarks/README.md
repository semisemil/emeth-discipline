추가 검사는 [검사 스크립트](superjson-probes.mjs)의 14개 진단 항목입니다. 공식 외부 테스트에 없던 다른 인스턴스의 cause 타입 복원을 포함합니다. 동일 참조 보존 두 항목과 문자열을 반환하는 custom Error serializer의 객체 변환 문제는 변경 전 코드에서도 재현되므로, 추가 진단 실패를 모두 새 회귀로 해석하지 않습니다.

검사 스크립트는 모델별로 None·Core·Workflow 제출 소스에 적용합니다. 저장소 루트에서 Node.js 22 이상으로 실행하며, `SEED`에는 변경 전 소스와 설치된 `esbuild` 의존성이 필요합니다. 각 소스 경로는 `src/`를 포함하는 프로젝트 루트입니다.

```bash
node docs/benchmarks/superjson-probes.mjs SEED NONE CORE WORKFLOW OUTPUT
```

결과는 `OUTPUT/probe-results.json`에 저장됩니다. 모델 호출은 없으며, 공식 외부 테스트 196개는 이 스크립트의 실행 대상이 아닙니다.
